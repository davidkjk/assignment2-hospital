## A. 정본(behaviors/목업)까지 손봐야 하는 것 (데모는 완료, 정본 반영만 대기)

### A-1. 이력 날짜 표기 — 데모는 개선함, 정본 미반영
정본 목업(`docs/design/mockups/50-history-list-full.html`)은 **연도 그룹만**(`.yr .rule` 가로줄) 있고 날짜 레일에 월(작게)/일(크게)/요일을 함께 그린다. 사용자 피드백(월이 일보다 너무 작다 · 월도 가로줄로 구분 · 연/월 구분을 중요시함).
- **데모 반영 완료**(커밋 `74ed63c`, 사용자 "확실히 월구분 있는 게 나은듯" 승인): **연/월 2단 그룹 헤더 + 가로줄**을 넣고, 날짜 레일은 **일 + 요일만**(월은 헤더로 올려 중복 제거·월이 크게 보임).
- **정본 미반영 = 할 일**: `screen-behaviors.md` 이력 절 + 목업 `50-history-list-full`에 **월 그룹(연/월 가로줄)·레일에서 월 제거**를 반영해야 데모↔정본이 일치.
- "일 숫자에 '일' 단위 없음(3 → 3일)"은 **월 헤더가 생겨 맥락이 분명**하므로 그대로 둠(정본도 그대로).

### A-2. 이력 옛 기록 탐색 수단 — 데모 완료(연도 바로가기), 정본 반영 대기
지금 이력은 스크롤 + `더 보기`(20건씩)뿐 → **연도 바로가기** 추가(사용자 확정 2026-08-22, `History.tsx`). 이미 있는 **연/월 그룹**을 살려, 화면 위 `바로가기 2026년 2025년…` 칩을 누르면 그 해가 렌더될 만큼 펼친 뒤 해당 연도 헤더로 스크롤한다(연이 2개 이상일 때만 노출). 기각: 기간 조회(어르신 입력 부담)·달력 점프(과함).
- **정본 반영 대기**: 정본 이력 화면(`HIST-*`)에 이 수단이 없음 → 나중에 `screen-behaviors`에 `연도 바로가기` 규칙 추가 고려.

## C. 검수 3차 (2026-08-22 후반) — 완료/미결/정본반영

### C-1. ✅ 로그인 화면 신설(진짜 갭이었음)
데모가 랜딩 [로그인]을 눌러도 **전화번호·비밀번호 입력 화면 없이 바로 홈**으로 갔음. 정본 `AUTH-LOGIN-01~09`대로 `/login` 신설(전화번호+비밀번호+눈토글·하이픈 자동·비번찾기/번호변경 링크, 평소 로그인은 OTP 없이 비밀번호). 랜딩=`AUTH-LAND-01`(버튼 2개)는 그대로. **정본 반영 불필요**(이미 정본에 있고 데모가 빠뜨렸던 것).

### C-2. ✅ 홈 카드를 정본 '풍부한' 카드로 승격 + 결정 복구
- 홈이 쓰던 간단 카드(삭제)가 정본보다 단순했음 → 정본 `HOME-CARD-01`·`DISP-CARD-01`·`CARD-OK/IN/WAIT-*`의 **가운데 132px 상태별 카드(StatusCard)**로 통일(홈·QA 동일). 상세=`DESIGN-NOTES.md`.
- **결정 복구**: 카드 교체로 사라졌던 것 되살림 — ⓐ 정본 색코딩 배지(예약확정=딥틸·신청=주황·대기=파랑·접수=보라, 공용 `StatusBadge`) ⓑ QR 눌러 전체화면(`NAV-HOME-02`). 사전문진 줄은 실제 상태(미작성/작성중(n/m)/완료 숨김) 반영.
- **정본 반영 불필요**(정본대로 맞춘 것).

### C-3. ⚠️ 취소 흐름 갭 (데모 미구현 — 다음 세션 할 일)
현재 데모 `[예약 취소]`는 **마감 후 상담 연결 화면(`ApptCancel`) 하나뿐**이다. 정본은 세 갈래인데 둘이 빠졌다:
- `CANCEL-NEW-01`: 예약 **만든 지 30분 이내면 마감과 무관하게 앱에서 바로 취소**(확인창 → 취소 완료). 근거 C-5·`CANCEL-NEW-02`(당일/내일 예약은 만든 순간 이미 마감 후라 유예 필요).
- **마감 전 일반 취소**: 확인창 → 바로 취소(현재 데모에 없음, 상담으로만 감).
- `CANCEL-LATE-01~06`: 마감 후 = **확인창 아니라 안내 팝업**(시계 아이콘·`취소 마감 시간이 지났습니다`·`진료 시작 N시간 전까지만`·상담채팅/전화, 채팅 먼저). 데모는 곧장 상담화면으로 보내 이 안내 팝업 단계가 없음.
- 데모엔 마감 데이터가 없으니, 다음 세션에 **간단한 마감 플래그/상태 기반 분기**(예: `예약신청` 또는 방금 만든 건=바로 취소, 특정 건=마감 후 상담)로 세 갈래를 다 보이게 할 것. **정본 반영 불필요**(정본에 이미 있음, 데모 미구현).
