# 2026-08-22 시각 정련 2차 (사용자 폰 검수 라운드) — 그림자·흰색·위계

> 사용자가 폰에서 훑으며 준 시각 피드백을 반영. 핵심 전환: **테두리 선을 없애고 그림자로 구분**, **쓰거나 고르는 요소는 흰색**. 값은 코드가 정본.

## 그림자·경계 시스템 (테두리 → 그림자)
- ⭐ **카드 바깥 테두리를 없애고 그림자로 띄운다.** 테두리 선이 "촌스럽다"는 사용자 지적. 흰 카드(`--card`) + 배경 틴트(`#F2F5F7`) 대비에 딥틸 톤 그림자를 얹어 구분. (위 「색·배경」 개정 역참조)
- **그림자 토큰 `--elevation-card`**(`index.css`): `0 0 10px`(사방 앰비언트, 위쪽도 은은히) + `0 1px 3px` + `0 10px 26px`(아래로 또렷). 딥틸 톤 `rgba(16,45,50,·)`. **한 곳에서 조절하면 전 카드 반영.** 사용자 요청으로 위쪽까지 잡히게(앰비언트) + 더 진하게 조정.
- **적용 범위**: `components/ui/card.tsx`(Card 전체) · 예약 마법사 선택 타일(Step1~3) · 예약 시간 슬롯(Step5) · 나의 예약 탭 행 · 예약 확인 요약 박스 · QR 카드. outline **버튼**도 테두리 제거 → `bg-card shadow-sm`(`components/ui/button.tsx`).
- **홈 카드 안의 카드(132px 상태 박스)**: 테두리 대신 또렷한 그림자(`0 2px 10px …0.14`)로 떠 보이게 + 배경을 **`bg-primary/10`**(약간 진한 딥틸)로 — 색+그림자 둘로 구분(사용자: 더 또렷하게).
- **입력칸은 예외 — 테두리 유지.** 그림자만으론 "쓰는 칸"으로 안 읽혀서. (아래 「흰색 규칙」)
- **점선 '추가' 버튼**(새 가족/기타 추가)은 유지 — '새로 추가' 어포던스라 그림자로 바꾸지 않음.

## "쓰거나 고르는 것 = 흰색" 규칙
- ⭐ 사용자 지적으로 확립: **입력·선택 요소는 흰색(`bg-card`) 상자**, 배경/컨테이너는 틴트. **잠긴(비활성) 칸은 배경색**(회색 채움 아님).
- **입력칸**: `components/ui/input.tsx` 기본 배경을 `bg-transparent`→**`bg-card`**로(전 입력칸 일괄: 로그인·회원가입·가족 등록·문진 등). 사전문진 textarea·이유 입력도 흰색. **테두리는 유지**(입력칸 표식).
- **잠긴 칸**: 가족 편집의 진료기록/병원연결 잠김 칸은 `disabled:bg-transparent`로 배경색과 같게(회색 채움 제거). 규칙 = "쓰는 칸 흰색 / 잠긴 칸 배경색".
- **선택 칩·타일**: 이력 이름/연도 칩 미선택 배경 흰색, 예약 선택 타일·시간 슬롯 흰색.

## 타이포 위계 (홈 카드 밋밋함 해소)
- 사용자 지적: "글자가 다 같은 체에 크기만 달라 밋밋". → **굵기+색 대비**로 위계: 이름=`font-bold` `text-lg`, **시간=진하게(`text-foreground` `font-semibold`)**, 진료과·의사=`muted`. 카드 본문도 앱 기준 17px(`text-base`)로 키움(카드 기본 `text-sm`이라 작아 보였음).
- **홈 카드 구분선**: 헤더 구분선이 카드 끝까지 닿고 나머지는 안쪽이라 들쭉 → **전부 안쪽(패딩 안)으로 통일**(끝까지 안 닿게).
- **의사 이름 중복 제거**: 홈 카드에서 진료과·의사가 헤더/하단 두 번 나오던 것 → 하단 반복 삭제 + 그 구분선도 제거(버튼만 남김).

## 의사 아바타 (`components/DoctorAvatar.tsx`)
- 실제 사진 파일이 없어(데모·오프라인) **자체 완결 SVG 일러스트**로 대체 — 의사마다 배경색·피부톤·머리·안경을 해시로 다르게(친근한 얼굴). **이름으로 시드**해 어느 화면이든 **같은 의사=같은 얼굴**.
- 적용: 예약 3단계(의사 선택)·예약 확인·예약 상세 담당의사. (실제 앱은 병원이 올린 `doctor.photoUrl` 사진이 이 자리.)
- 사용자 방침: 실제 사진이 비싸면 일러스트, 국적 무관.

## QR 화면 재정비 (`QrGraphic.tsx` · `QrFullscreen.tsx`)
- 사용자 지적: 가짜 8×8 격자 + 흩어진 텍스트라 "이상함". → **진짜 QR 같은 그래픽**(`QrGraphic`: 모서리 인식패턴 3개·타이밍 라인·약 48% 촘촘한 모듈, `booking_code`로 시드)로 교체(스캔되진 않음). 레이아웃은 **흰 QR 카드**(QR+예약번호) + 이름·안내·예약정보 정리, 좌우 전환은 하단 `n/m`과 함께.

## 예약 시간 — 10분 간격 데이터 (정본 그대로 확인)
- 사용자 우려(슬롯이 10분이면 하루 칸이 너무 많음)에 대응해 **10분 간격 진료 의사**(이비인후과 정우재, `getSlots`) 데이터 추가. 정본 `BOOK-TIME-01`의 **오전/오후 3열 격자**가 촘촘함을 압축해 담음을 실제로 보여줌(세로 레일 금지 `BOOK-TIME-05`). 구조 변경 없이 데이터만.

## 자잘한 수정
- **사전문진 수정 진입('확인'에서 한 문항 고치기)** 시 '이전' 버튼 숨김(돌아갈 곳은 확인 화면 하나뿐).
- **예약탭 사전문진 줄** hover 피드백 추가(변화 없던 것).
- **기존환자 연결 안내문구**: 열거 방지 메타설명("맞든 아니든 같은 화면…")이 어르신께 혼란 → 동작은 그대로, 문구만 "본인 확인을 위해 인증번호를 보내드려요…"로 쉽게, 상자도 경고색→회색.

# 직원 웹 (`routes/staff/`) — "직원 콘솔" 정체성 (2026-08-22 신설)

> 사용자 확정(예시 보고 결정): 직원웹은 **환자앱과 다른 "체급"**을 갖는다. 브랜드 가족은 같되 느낌은 업무 도구.

## 왜 환자앱 토큰을 그대로 안 쓰나
- 처음엔 환자앱 토큰을 그대로 얹었더니 **"환자앱을 넓은 화면에 키운 것"**처럼 보였다(사용자 지적, "환자앱에서 쓴 토큰 쓴 느낌"). 
- **환자앱** = 어르신용 소비자앱 — 큼직·둥글(rounded-2xl)·17px·폭신한 그림자 카드(`--elevation-card`). 편안함이 목적.
- **직원 웹** = 하루종일 반복 업무하는 **도구** — 밀도·또렷한 구조·빠른 스캔이 목적. 폭신한 소비자앱 느낌이면 업무에 방해.
- 결론: **같은 브랜드 가족, 다른 체급.**

## 유지(브랜드 가족)
- 딥틸 `--primary`(#0B6E70)·**Do Hyeon 워드마크**·Pretendard·**주의색 amber**(주황, 예약신청 배지와 같은 색)·Phosphor 채움 아이콘·shadcn 공용 부품(`components/ui`·`components/icons`).

## 직원 콘솔만의 것
- **딥틸 잉크 사이드바**(`bg-[#0a4a4c]`, primary보다 진한 잉크) + 흰 글자. ⭐ **환자앱은 전 화면 흰색**이라 이 하나로 두 surface가 확실히 갈린다. 활성 항목=`bg-white/12`+흰 글자+좌측 3px 흰 바(`SHELL-NAV-06`), 배지=amber-400(딥틸 위에서 도드라지게), 그룹 라벨=white/55.
  - ⚠️ 환자앱 `DESIGN-NOTES`의 "딥틸 톤 바 기각(teal-on-teal 탁함)"과 안 부딪힌다 — 그건 **딥틸 아이콘/글자를 딥틸 바에** 얹은 경우고, 여기는 **딥틸 슬래브에 흰 글자**(고대비)라 다르다.
- **각지고 촘촘한 패널**: 폭신 그림자 카드 → **얇은 경계선(`border-border/70`) + 미세 그림자(`0 1px 2px`)·`rounded-xl`**. 데이터 패널 느낌.
- **업무용 밀도**: 본문 기준 `text-sm`, 촘촘한 간격(행 `py-2.5`), 섹션 제목 `text-base`(환자앱은 큼직). 헤더는 그림자 대신 하단 실선(`border-b`).
- 헤더 왼쪽 = **현재 화면 제목**(병원명은 사이드바 브랜드가 상시 표시). 오른쪽 끝 = 역할칩·로그아웃(확인창)·구분선·`[새 예약][당일 방문]`(`SHELL-HDR-*`·`SHELL-ACT-01`).
