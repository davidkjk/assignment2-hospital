# 상담봇 지식 관리 안내서 (관리자용)

> 상담봇이 환자에게 답할 때 쓰는 **병원 안내 자료(지식 문서)**를 추가·수정·승인하는 방법입니다.
> 화면 그림은 실제 배포 화면 캡처로 채웁니다(검수 때 확정). 접속: `https://gaonhospital-staff.vercel.app`.

---

## 1. 상담봇이 답하는 원리 (짧게)
- 환자가 "주차장 있나요?"처럼 물으면, 상담봇은 **등록된 지식 문서 중 질문과 가장 가까운 내용을 찾아** 그 내용을 바탕으로 답합니다(이를 RAG=Retrieval-Augmented Generation, "찾아서 답하기"라고 합니다).
- 그래서 **지식 문서가 정확하고 최신일수록 상담봇 답변이 정확**합니다. 상담봇은 문서에 없는 사실을 지어내지 않도록 설계돼 있고, 못 찾으면 직원 연결로 넘깁니다.
- 진단·처방 같은 의료 판단은 하지 않습니다(직원 연결).

## 2. 자료 추가·수정하는 화면 사용법
1. 좌측 **"지식 관리"**(상담봇 자료)로 들어갑니다.
2. **"새 문서"**로 제목과 내용을 작성합니다(예: 제목 "주차 안내", 내용 "지하 1~2층, 2시간 무료…").
3. 기존 문서는 목록에서 열어 **내용을 수정**합니다.
4. 자료는 짧고 명확한 문단으로 나눠 쓰면 상담봇이 더 잘 찾습니다.

_(그림: 지식 문서 목록·편집 — `images/kb-editor.png`)_

## 3. 승인 절차 (수정 → 승인 → 반영)
- 자료를 바로 상담봇에 반영하지 않고 **승인 단계**를 둡니다(실수로 잘못된 안내가 나가는 것을 막기 위해).
  1. 작성/수정 → **검토 대기** 상태로 저장.
  2. 관리자가 내용을 확인하고 **승인**.
  3. 승인된 내용만 상담봇 답변에 **반영**됩니다.
- 승인 전 내용은 상담봇이 쓰지 않습니다.

_(그림: 승인 대기·승인 버튼 — `images/kb-approval.png`)_

## 4. 이전 내용·수정 이력 확인
- 각 문서는 **수정 이력**이 남아, 언제 누가 무엇을 바꿨는지 볼 수 있습니다.
- 잘못 바꿨을 때 이전 내용을 참고해 되돌릴 수 있습니다.

_(그림: 수정 이력 — `images/kb-history.png`)_

## 5. 상담봇 답변이 이상할 때 점검 순서
1. **해당 주제의 지식 문서가 있는지** 확인 — 없으면 새로 추가.
2. 문서 내용이 **정확·최신인지** 확인 — 오래된 정보면 수정 후 **승인**.
3. 문서가 **승인 상태인지** 확인(검토 대기면 상담봇이 안 씀).
4. 그래도 이상하면 **시스템 오류** 화면에서 "서비스 장애"(AI 연동) 기록 확인 → `error-check.md` 참고.
5. 특정 질문이 계속 직원 연결로만 넘어가면, 그 질문에 맞는 지식 문서를 보강합니다.
