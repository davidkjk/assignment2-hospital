# 관리자 사용설명서

> 관리자(예: `admin@gaon.local`) 전용 기능입니다. 화면 그림은 실제 배포 화면 캡처로 채웁니다(검수 때 확정).
> 접속: `https://gaonhospital-staff.vercel.app`.

---

## 1. 직원 계정 초대·사용 중지
1. 좌측 **"직원 관리"**로 들어갑니다.
2. **"직원 초대"**로 이메일·역할(관리자/접수/의사)·이름·진료과를 정해 초대합니다.
3. 초대만 하고 아직 로그인하지 않은 직원은 **"초대함 · 아직 안 들어옴"**으로 표시됩니다.
4. 퇴사 등으로 더 이상 쓰지 않는 계정은 **사용 중지**합니다(기록은 남고 로그인만 막힘).

_(그림: 직원 관리 목록 — `images/admin-staff.png`)_

## 2. 진료과·의사 일정 관리 (휴진 등록과 영향 예약 재조정)
1. **"일정 관리"**에서 특정 의사의 특정 날짜를 **휴진(예외)**으로 등록합니다.
2. 그 날짜에 **기존 예약이 있으면 경고**와 함께 영향받는 환자 목록이 나옵니다.
3. 직원이 환자별로 **시간 변경 또는 취소**를 처리합니다 — 처리 결과가 환자 앱·알림에 반영됩니다.

_(그림: 휴진 등록·영향 예약 목록 — `images/admin-schedule.png`)_

## 3. 운영 통계 보는 법·파일 다운로드
1. **"통계"** 화면에서 오늘(또는 기간)의 예약·방문·취소·**예약 부도**·평균 대기시간·상담봇 문의·직원 연결 현황을 봅니다.
2. 필요한 목록은 **CSV 다운로드** 버튼으로 파일로 내려받습니다(엑셀에서 열림).

_(그림: 통계 대시보드 — `images/admin-stats.png`)_

## 4. 상담 문의 관리 (이관된 상담 응대)
1. 상담봇이 답하기 어려운 질문은 **"확인 필요 상담 문의"**로 넘어옵니다(건수 배지로 표시).
2. 문의를 열면 **대화 요약**이 보입니다. 담당 직원이 답변을 작성하면 환자 앱/상담창에 도착합니다.
3. 처리한 문의는 상태를 정리합니다.

_(그림: 상담 문의 목록·상세 — `images/admin-tickets.png`)_

## 5. 시스템 오류 화면 보는 법
- 좌측 **"시스템 오류"**에서 최근 오류를 확인합니다(개인정보·비밀키는 가려짐, 읽기 전용).
- **"서비스 장애"** 배지가 붙으면 외부 서비스(문자·상담봇 AI) 쪽 문제입니다.
- 자세한 점검 순서는 `error-check.md`를 참고하세요.

_(그림: 시스템 오류 — `images/admin-errors.png`)_

## 6. 병원 설정 (취소 마감 시간 등)
- **"설정"**에서 취소 마감 시간, 앱 예약 자동 확정 여부, 병원 안내(위치·시간) 등을 조정합니다.
- 되돌리기 어려운 설정은 확인창 안에서만 바꿀 수 있게 되어 있습니다.

_(그림: 병원 설정 — `images/admin-settings.png`)_
