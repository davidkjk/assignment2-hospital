# 직원 사용설명서 (접수직원·의사용)

> 컴퓨터에 익숙하지 않아도 따라 할 수 있게 썼습니다. 화면 그림은 실제 배포 화면 캡처로 채웁니다(검수 때 확정).
> 접속: `https://gaonhospital-staff.vercel.app` · 로그인 = **이메일 + 비밀번호**.

---

## 1. 로그인과 비밀번호 변경
1. 주소로 접속하면 로그인 화면이 나옵니다. 받은 이메일(예: `reception@gaon.local`)과 비밀번호를 입력합니다.
2. 처음 로그인하면 비밀번호를 바꾸도록 안내됩니다. 새 비밀번호를 정해 저장합니다.
3. 비밀번호를 잊으면 로그인 화면의 "비밀번호 찾기"로 재설정 링크를 받습니다.

_(그림: 로그인 화면 — `images/staff-login.png`)_

## 2. 오늘의 병원 현황 보는 법
- 로그인하면 **오늘의 현황**이 먼저 보입니다: 오늘 예약 수, 도착·대기 인원, 진료 중/완료 현황.
- 숫자를 누르면 해당 목록으로 이동합니다.

_(그림: 오늘의 현황 — `images/staff-today.png`)_

## 3. 예약 캘린더 (신규 예약·변경)
1. 좌측 **"예약 캘린더"**에서 날짜·의사를 고릅니다.
2. **빈 시간**을 누르면 새 예약을 등록합니다(환자 검색 → 시간 확인 → 저장).
3. 기존 예약을 누르면 **시간 변경·취소**를 할 수 있습니다.
4. 시간이 겹치거나 이미 찬 자리는 경고가 뜹니다 — 안내에 따라 다른 시간을 고릅니다.

_(그림: 예약 캘린더 / 예약 등록 패널 — `images/staff-calendar.png`)_

## 4. 환자 도착 접수와 대기 순서 관리
1. 예약 환자가 오면 목록에서 **"도착"**을 눌러 대기로 넘깁니다.
2. 예약 없이 온 환자는 **방문(워크인) 접수**로 등록하면 바로 진료대기가 됩니다.
3. 대기 순서는 목록에서 조정할 수 있습니다.

_(그림: 대기 목록 — `images/staff-queue.png`)_

## 5. 환자 정보·과거 기록 조회
- 환자를 검색해 기본 정보와 과거 방문·진료 이력을 봅니다.
- 개인정보 보호를 위해, 존재하지 않는 환자를 찾아도 있는 것과 같은 화면으로 진행됩니다(정보가 새지 않도록).

_(그림: 환자 상세 — `images/staff-patient.png`)_

## 6. (의사) 진료 화면
1. **본인 대기 목록**에서 다음 환자를 확인합니다.
2. **사전문진**과 **과거기록**을 봅니다.
3. 진료기록을 작성합니다. **자주 쓰는 문구**를 등록해두면 빠르게 입력할 수 있습니다.
4. **임시저장** 후 진료가 끝나면 **완료** 처리합니다 — 완료하면 환자 앱 상태가 "완료"로 바뀝니다.

_(그림: 의사 진료 화면 — `images/doctor-console.png`)_

## 7. 완료된 기록 수정과 사유 입력
- 완료된 기록의 오타 등을 고칠 때는 **수정 사유를 반드시 입력**합니다.
- 이전 내용과 새 내용이 **둘 다 이력에 남습니다**(무엇을 언제 왜 바꿨는지 추적).
- 접수 직원은 진료기록을 수정할 수 없습니다(의사 권한).

_(그림: 기록 수정 이력 — `images/record-revision.png`)_
