# 상담봇 직원 웹 — 상담 관리 동작 명세

> 범위: 직원 웹 상담 관리 8화면. 환자 앱·웹 상담창·관리자 화면의 동작은 정의하지 않는다.

> 정본 우선순위: `docs/design/chatbot-source-of-truth.md`가 옛 스펙과 충돌하면 정본이 이긴다. 특히 마감 후 취소·변경은 전용 `/cancellation-requests`를 만들지 않고 `/today` → 예약 캘린더의 ⚠ → 기존 예약 사이드패널에서 처리한다. `[상담 채팅 연결]`을 누른 즉시 취소 상담 기록이 생긴다.
