# 환자 앱 AI 상담봇 동작 명세

> ⚠️ MERGED → docs/ (2026-08-13). 이 파일은 아카이브. 이후 변경은 docs/ 정본에 직접.

> 범위: 환자 앱(Flutter)의 `AI 상담` 19프레임. 웹 상담창·직원 웹·관리자 화면은 정의하지 않는다.
>
> 우선순위: `docs/design/chatbot-source-of-truth.md`가 다른 문서와 충돌하면 정본을 따른다. 카드 9종의 내용·상태·버튼은 `docs/design/chatbot-card-catalog.md`를 그대로 소비하며 이 문서에서는 대화 흐름 안의 위치·표시 조건·화면 연결만 정한다.
>
> 공통 문구: 환자 노출 이름은 `AI 상담봇`, 하단 탭만 `AI 상담`이다. 취소가 확정되기 전에는 `취소 요청이 접수/등록됐다`고 쓰지 않고 `상담(직원 확인)으로 연결됐다`와 `아직 예약은 유지되고 있습니다`만 쓴다.
