흐름 4 예약 변경과 취소

변경은 날짜·시간만 다시 고릅니다(4~5단계). 서버에서 "변경"은 실제로 취소 + 새 예약이고 진료과는 바꿀 수 없으므로, 고르게 해놓고 무시하면 조용한 거짓말이 됩니다. 의사를 바꾸고 싶은 분을 위해 다른 의사도 보기 링크를 둡니다. 취소는 마감 전이면 확인창 하나로 즉시 처리되고, 마감 후에는 상담을 거쳐 직원이 처리합니다 — 이 경로에서는 "취소 요청이 접수되었습니다"라고 말하지 않습니다. 8/1에 직원이 거절했을 때의 화면도 새로 만들었습니다(갭 #12).
⭐ 마감 후 「시간 변경」도 취소와 똑같이 상담으로 보냅니다(갭 #24) — 그러지 않으면 마감 후 취소가 막힌 사람이 예약을 2주 뒤로 옮긴 뒤 곧바로 취소해 마감 규칙을 우회할 수 있고, 임박한 자리는 빈 채로 남습니다. 화면은 아래 취소용을 그대로 쓰고 문구만 다릅니다: 변경 마감 시간이 지났습니다 / 시간 변경은 직원 확인이 필요합니다.
