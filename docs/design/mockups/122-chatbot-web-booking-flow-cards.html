웹앱취소 = 봇이 실행하지 않고 안내

요구사항 L49: 상담봇은 예약 변경·취소를 안내만 한다(실행 아님). 봇은 취소를 실행하지 않고, 취소 화면 경로와 직원에게 연결 칩을 준다. 문구는 채널로 갈린다 — 웹은 “앱의 예약 내역”, 앱은 사용자가 이미 앱 안이라 “예약 내역 화면”.

WEBCHAT-CANCEL-GUIDE · BOOK-BOT-WIZARD-CANCEL

웹 자연어 취소

예약 취소는 앱의 예약 내역에서 직접 하시거나, 직원 상담으로 도와드릴 수 있어요.

quick_replies 카드 재사용(options 비움 + handoff_chip). 예약 진료과 카드로 새지 않는다.

앱 자연어 취소

예약 취소는 예약 내역 화면에서 직접 하실 수 있어요. 도움이 필요하시면 직원 상담으로 연결해 드릴게요.

앱은 이 카드를 입력창 슬롯 칩으로 띄운다. “내과 예약 취소해줘”처럼 진료과명이 함께여도 취소가 우선 — 마법사로 새지 않는다.
