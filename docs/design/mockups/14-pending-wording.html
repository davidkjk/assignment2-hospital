2. 카드 위에 상태 띠를 따로

예약 카드는 건드리지 않고, 그 위에 상태 전용 띠를 하나 올립니다. 시계 아이콘이 "기다리는 중"을 보강합니다. 확정되면 이 띠만 사라지므로 확정 전후 화면 차이가 가장 작습니다. 단점: 화면에 요소가 하나 늘어납니다.

3. 머리 안에 두 줄로

회색 머리 안에 상태를 첫 줄, 날짜를 둘째 줄로. 요소가 늘지 않으면서 상태 글자가 15px로 커집니다. 상태와 날짜가 한 덩어리로 묶여 "이 예약이 확인 중"이라는 관계가 분명합니다.

추천

3(머리 안에 두 줄)을 추천합니다. 상태가 충분히 크면서도(15px + 시계 아이콘) 날짜·시간이 밀려나지 않고, 화면에 새 요소가 늘지 않습니다. 무엇보다 상태와 그 상태가 적용되는 예약이 한 상자 안에 있어서, 예약이 여러 건일 때 "어느 예약이 확인 중인지" 헷갈릴 여지가 없습니다.

1번은 상태 인식이 가장 빠르지만 날짜가 두 번째로 밀리는 게 아깝습니다 — 사용자가 이 화면을 여는 첫 번째 이유는 여전히 "언제였지?"입니다. 2번은 확정 전후 차이가 가장 작아 만들기 편하지만, 띠와 카드가 따로 놀아 보입니다.

문구 "아직 확정 전" 대신 "직원 확인 중입니다"로 확정합니다. 지적하신 대로 누가 무엇을 하고 있는지가 드러나서, 사용자가 "내가 뭘 더 해야 하나?" 하고 불안해하지 않습니다.
