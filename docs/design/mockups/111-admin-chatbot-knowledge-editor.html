KBADM-EDITOR-04
승인 후 정정
승인 취소는 없습니다. 수정이력의 [편집]으로 내용을 채워 새 수정본으로 검토한 뒤 다시 승인합니다. KBADM-EDITOR-14
안내자료를 승인하시겠습니까?

승인하면 이 수정본이 AI 상담봇 답변에 반영되며 되돌릴 수 없습니다.

승인 뒤 즉시 시작되는 작업
내용을 다시 나누고(재청킹) 임베딩을 새로 만듭니다. 완료되기 전에는 기존 승인본이 계속 사용됩니다.
  • 분류: 검사 전 준비사항
  • 제한 자료: 상담봇이 직접 답하지 않고 입력 문구만 그대로 표시
  • 정정하려면 [편집] 후 새 수정본을 다시 승인해야 함
