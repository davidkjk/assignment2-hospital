직원 웹 전체 화면 흐름

직원 로그인에서 역할별 기본 화면으로 분기한 뒤, 04a–04l의 12개 화면과 기존 공통 셸 이동을 연결한다. 실선은 확정된 이동, 점선은 조건부 이동, 붉은 점선은 목적지·계약이 아직 확인되지 않은 빈틈이다.

공통 진입

/login · 직원 로그인

직원이 역할을 선택하지 않는다. 서버가 활성 staff.role을 읽어 기본 화면을 정한다.

접수직원 기본

/today · 오늘의 현황

대기·확인 필요 업무를 시작한다. 공통 셸에서 접수, 환자 검색, 안내 보내기로 이어진다.

의사 기본

/doctor/console · 진료 화면

담당 대기 환자와 문진을 확인한다. 사이드바에는 환자 검색만 둔다.

관리자 기본

/today · 오늘의 현황

접수직원 업무를 확인하면서 관리자 사이드바의 운영 화면으로 이동한다.

접수직원 · 관리자

/checkin · QR·예약번호 접수

QR을 먼저 스캔하고 예약번호 입력을 보조로 쓴다. 결과 카드에서 도착 처리하며 성공 뒤에도 같은 화면에 남는다.

공통 환자 업무

/patients · 환자 검색

접수직원·의사·관리자가 역할 범위 안에서 환자를 찾는다. 행 선택은 상세로 이어진다.

접수직원 · 관리자

/messages · 안내 보내기

새 발송은 오른쪽 패널에서 끝내고, 실패 명단의 환자 열기는 상세로 연결한다.

공통 상세

/patients/:id · 환자 상세

예약·방문·문진·완료 기록·문의·내부 메모를 역할 범위에 맞게 확인한다.

관리자

/admin/staff · 직원 관리

초대·재초대·타인 사용 중지. 영향 예약이 있으면 정책 승인 뒤 /today 확인 필요로 넘긴다.

관리자

/admin/access-logs · 열람 기록

환자 선택은 같은 화면의 필터만 바꾼다. 조회 실패는 화면 안에서 재시도한다.

관리자

/admin/questionnaires · 문진표 관리

진료과 선택·새 버전 저장·과거 버전 읽기 전용 미리보기는 같은 화면 안에서 닫힌다.

관리자

/admin/patient-merge-candidates

후보 비교와 병합 검토를 거친다. 원문 확인은 /patients/:id로 갔다가 후보 목록으로 돌아온다.

관리자

/admin/errors · 시스템 오류

기간 조회·최근 오류 확인. 발송 실패 명단으로 자동 이동하지 않고 /messages에 결과를 남긴다.

관리자

/admin/stats · 운영 통계

기간 조회·드릴다운·CSV는 현재 화면에서 끝난다. 환자 상세나 새 화면으로 보내지 않는다.

관리자

/admin/settings · 병원 설정

저장·오류·409는 현재 화면에 남는다. 예정 휴무의 관리 링크만 특정 날짜 변경으로 이어진다.

범위 밖 참조

/admin/schedule · 특정 날짜 변경

원본 SCHED-EXC-18과 04l HSETX-NAV-01이 목적지를 가리키지만, 이 작업의 12개 화면 밖이며 구현 계약은 차단 상태다.

계약 확인 필요
기존 소비 위치

/today · 확인 필요 예약

의사 사용 중지 후 영향 예약을 처리하는 기존 접수 흐름. STAFF-DEACT-07의 정책 A가 승인될 때만 확정된다.

조건부

모든 역할·화면에 공통으로 닫힌 예외 흐름

세션 만료

현재 route와 필요한 필터를 기억해 /login으로 이동한 뒤 인증 성공 후 원래 화면으로 복귀한다. 기존 NAV-SHELL-08 인용.

권한 부족

로그인 화면으로 쫓아내지 않고 권한 안내와 역할별 기본 화면 버튼을 제공한다. 기존 NAV-SHELL-05·SHELL-URL-01 인용.

조회·저장 오류

화면을 바꾸지 않고 실패한 영역에 [다시 시도]를 둔다. 기존 NAV-GLOBAL-07·ERR-*·EMPTY-* 인용.

로그아웃

공통 셸에서 /login으로 가며 뒤로가기로 직원 화면을 노출하지 않는다. 기존 NAV-SHELL-06 인용.

이 흐름도의 화살표는 고객이 눈으로 보는 곳이고, 구현 시 기계가 확인할 이동 규칙은 동반 명세서 04m의 기존 NAV-* 인용과 NAVX-STAFF-* 표에 있다. 04m에서 새로 만든 NAVX는 기존 NAV-*를 복제하지 않는 두 개의 합성 경로뿐이다.
