김순자님 2
… 홈 화면 …

숫자 배지는 읽지 않은 개수. 0이면 배지가 사라지고 종만 남습니다.
설정(톱니)과 나란히 앱바 우상단에 둡니다 — 이미 확정된 배치입니다(햄버거 없음).

알림 종류 → 눌렀을 때 가는 곳
· 예약 신청·확정 → 예약 상세
· 병원발 변경 → 예약 상세 (카드 위 `[확인]` 안내문이 함께 보인다)
· 병원발 취소 → ⭐ 이력 탭의 그 줄 (예약이 이미 없다 — 오늘 확정한 #23이 이 문을 만들었다)
· 사전문진 안내 → 사전문진 작성 화면
· 전날·당일 안내 → 예약 상세
· 상담 답변 → 상담방
· 진료 후 안내 → 이력 탭의 그 줄(병원 안내문이 펼쳐진 상태)
이 화면이 없으면 생기는 일
· 잠금화면 알림을 밀어버린 사람은 무슨 일이 있었는지 영영 모른다.
· 알림을 종류별로 끌 수 있게 설계했으므로(확정), 꺼둔 사람에게는 통로가 하나도 안 남는다.
· 특히 병원발 변경·취소는 놓치면 다른 시간에 병원에 간다 — 이번 프로젝트에서 실제 손해가 가장 큰 항목이다.

⚠️ 끈 알림은 알림함에도 남지 않는다(확정). 사용자가 "껐다"고 한 것이 화면 어디에도 안 나타나는 것이 맞다.

필요한 것: 알림 저장 테이블 + 목록 API + 읽음 처리 + 30일 정리. 발송 시점에 보내는 것과 같은 내용을 한 벌 더 남기면 된다.
