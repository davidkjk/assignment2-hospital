예약은 되돌아가면 뒤 단계가 초기화됩니다 — 의사를 바꾸면 날짜·시간을 다시 골라야 하죠. 그래서 "칩으로 점프"가 "뒤로 여러 번"과 결과가 같았고, 되돌리기 경로를 하나로 통일하는 게 단순했습니다.

문진은 문항끼리 독립적이라 초기화가 없습니다. 3번을 고쳐도 4·5·6번 답은 그대로입니다. 그러니 6번 화면에서 1번을 고치려고 뒤로를 다섯 번 누르게 할 이유가 없습니다. 같은 규칙을 기계적으로 적용하는 것보다, 각 화면의 성질에 맞추는 게 맞습니다.

함께 확정되는 것 ① 문항마다 자동 저장 + 상단 "저장됨" 표시 ② 재진입 시 이어쓰기 화면(②번) ③ 🔄 진료가 시작된 이후(상태 진료중)에 같은 화면이 읽기 전용으로 바뀌고 [고치기]·[제출하기]가 사라지며 "진료가 시작되어 수정할 수 없습니다" 표시 ④ 챗봇이 저장한 값도 이 화면에 항상 최신으로 반영(화면이 열릴 때마다 다시 불러옴).
