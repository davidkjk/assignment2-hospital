이 화면이 지키는 규칙

①~④는 2026-07-31에 확정된 것이고, ⑤만 2026-08-04(묶음 8)에 추가된 결정입니다(B-43).

① 홈과 역할을 나눈다

담는 내용이 겹치는 것은 허용하되 성격을 다르게 합니다.
홈

기각: 목록에서 오늘 것을 빼 겹침을 없애기 — "내 예약 다 보여줘" 했는데 오늘 게 없는 목록이 됩니다.

② 줄에 버튼을 두지 않는다

변경·취소·문진·QR을 줄마다 붙이면 6건 기준 버튼 24개가 되어 요구사항 4.8("중요한 버튼을 여러 개 작게 배치하지 말 것")과 정면충돌합니다. 줄을 누르면 어차피 상세로 가므로 지름길을 둘 이유가 없습니다.
예외는 사전문진 하나 — 미작성인 줄에만 경고 줄을 하나 더 붙입니다. 작성완료는 표시하지 않습니다(급하지 않고, 표시하면 대부분의 줄이 회색 줄로 두 배가 됩니다).

③ 담는 범위 — 앞으로 갈 예약만

취소·완료된 예약은 넣지 않습니다. 그것들이 갈 곳은 이력 탭입니다(8/1 확정 — 목업 38번). 전부 담으면 이력 탭과 역할이 겹쳐 탭 하나가 무의미해집니다.

④ 상태는 오른쪽 작은 글씨 하나로만

확인 중 = 병원이 아직 승인하지 않음(레일도 진한 회색). 승인되면 실시간으로 저절로 사라집니다.
상담 연결됨 = 마감 후 취소·변경을 문의 중.
🆕 시간 지남(주의색) = 예약 시각이 지났는데 접수가 안 된 것. 앞의 둘은 회색이지만 이것만 주의색입니다. ⚠️ 정시가 아니라 예약 시각 + 30분부터입니다(B-13) — 그 시각 이 화면을 보는 사람은 대부분 이미 병원에 와서 접수 줄에 서 있는 사람이라, 정시에 바꾸면 창구 앞에 선 사람이 병원에 전화를 겁니다. 이 표시를 두는 이유는 노쇼 방지가 아니라 중복 요청 방지입니다 — 목록에 아무 변화가 없으면 "요청이 안 들어갔나?" 싶어 채팅에 다시 쓰거나 병원에 전화하게 됩니다.
⚠️ "취소 요청이 접수/등록되었다"는 표현을 쓰지 않습니다(환자 노출 문구 원칙).

⑤ 🆕 「시간 지남」에는 경고 줄을 붙이지 않는다 B-43

결정을 가른 사실: 시간이 지난 예약은 반드시 오늘 예약이고, 홈은 「가장 가까운 하루치」를 반드시 보여줍니다(HOME-SCOPE-01). 즉 이 예약은 홈 화면에 100% 나타나고, 홈에는 이미 예약 시간이 지났습니다 한 줄과 큰 버튼 두 개(상담·전화)가 떠 있습니다. 목록이 이중으로 경고할 값이 낮습니다.
그래서 목록에는 병원에 연락해 주세요도 [상담 채팅 연결]·[병원 전화]도 두지 않습니다.
⛔ 기각(경고 줄 붙이기): ②의 예외가 하나에서 둘로 늘어납니다. 문진 미작성과 겹치면 한 예약에 경고 줄이 두 개 달려, 요구사항 4.8이 막으려던 화면이 됩니다.

v1에서 고친 것 두 가지 (사용자 지적)

① "사전문진 미작성이 위 예약 것인지 아래 것인지 모르겠다" — v1은 줄들을 나란히 놓고 경고를 그 사이에 끼워 넣어, 경고가 위·아래 어느 예약에 붙는지 자리로 말해주지 못했습니다. 잘못 읽으면 다른 예약의 문진을 쓰게 되는 문제라 그냥 둘 수 없었습니다. 두 가지로 고쳤습니다:
· 한 예약 = 한 상자. 줄과 그에 딸린 경고를 같은 테두리 안에 넣고 예약끼리는 상자를 띄웠습니다. 테두리가 "여기까지가 한 예약"을 말합니다.
· 주의색 바를 레일 오른쪽 끝(74px)에 세웠습니다. 경고 글자가 위 줄의 이름·진료과와 같은 세로선에서 시작하므로, 눈이 위로 이어집니다. 홈 화면의 사전문진 줄과 같은 문법입니다.
⚠️ 확인용으로 미작성을 두 건(김순자·김하윤) 넣었습니다. 상자가 떨어져 있어도 각각 자기 예약에 붙어 보이는지 봐주세요. 김하윤은 확인 중 + 미작성이 겹친 줄입니다 — 진한 회색 레일과 주의색 경고가 한 상자 안에서 부딪히지 않는지도 함께 봐주세요.
② "날짜 글씨가 눈에 잘 안 띈다" — 12.5px 회색 → 15px 잉크색으로 올리고 건수(3건)와 가로선을 붙였습니다. 날짜는 이 화면의 뼈대라(예약을 날짜로 찾으므로) 줄 안의 이름(14px)보다 커야 맞습니다. v1은 오히려 더 작고 흐렸습니다.

아직 봐주실 것

① 상자 사이 간격(9px)이 충분히 떨어져 보이는지 — 붙어 보이면 다시 한 덩어리로 읽힙니다.
② 날짜 머리에 붙인 건수(3건)가 도움이 되는지, 아니면 군더더기인지.
③ 확인 중(진한 회색 레일)과 상담 연결됨(주의색 글씨)의 구분 — v1에서 잘 된다고 하셨으니 이번에도 유지되는지만.
