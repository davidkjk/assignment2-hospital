# 화면 목업 (환자 앱)

2026-07-31 비주얼 컴패니언 세션에서 만든 HTML 목업. **브라우저로 열어** 보면 된다(별도 서버 불필요, 웹폰트만 인터넷에서 받아온다).

결정 내용과 근거는 [`docs/superpowers/specs/2026-07-31-ui-design-decisions.md`](../../superpowers/specs/2026-07-31-ui-design-decisions.md)에 있다. **이 폴더는 그림, 그 문서가 원본이다.**

> **목업은 조감도이지 코드가 아니다.** HTML/CSS로 그렸지만 실제 구현은 Flutter(환자 앱)·React(직원 웹)다. 구현 결과를 눈으로 대조하는 용도로 쓴다.

## 읽는 법

- 앞 번호가 **결정 순서**다. `-v2`/`-v3` 접미사는 같은 화면의 수정본이고 **뒤 번호가 최종**이다.
- ~~취소선~~은 뒤에 나온 파일로 대체된 것이라 참고만 하면 된다.
