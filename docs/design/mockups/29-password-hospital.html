비밀번호 변경을 넣는 근거

요구사항 4.1은 "잊었을 때 찾기"만 요구하고 변경은 말하지 않습니다. 그래도 넣자고 제안드리는 이유는 두 가지입니다.

① 비밀번호가 남에게 노출된 것 같을 때 바꿀 방법이 지금은 없습니다. 로그아웃하고 "비밀번호 찾기"로 문자 인증을 다시 받아야 하는데, 이건 우회로지 정상 경로가 아닙니다.

② 추가 비용이 거의 없습니다. 설정 진입 시 이미 비밀번호 재인증이 있어 본인 확인이 끝나 있고, 비밀번호를 실제로 바꾸는 코드(auth.updateUser)는 비밀번호 찾기 화면에서 이미 씁니다. 화면 하나만 새로 만들면 됩니다.
